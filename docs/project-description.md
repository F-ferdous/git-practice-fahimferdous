# Project Description

## Overview

`Git Practice` is a small learning repository designed to help developers practice basic Git workflows, including commits, branching, and collaboration.

## Purpose

The project provides a simple Python codebase with a main entry point and utility module so learners can focus on version control without complex application logic.

## Structure

- `src/main.py` — application entry point
- `src/utils.py` — helper functions and support utilities

## Goals

- Practice writing clear commit messages
- Learn how to create and merge branches
- Explore basic project organization in a Git repository

## Notes

Keep the repository lightweight so the focus remains on Git fundamentals and collaboration practices.
